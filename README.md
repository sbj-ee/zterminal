# zterminal

A PuTTY-like terminal emulator for Linux, built with C++20, Qt 6 Widgets, and libvterm.

**Status:** planning / early development. Nothing is released yet.

Planned for v1: xterm-compatible emulation with 16/256/24-bit color, X11-style mouse
copy/paste (select copies, right-click pastes), saved sessions (local shell, SSH via
the system `ssh`, serial console), a classic menu bar, and a `.deb` for Linux amd64.

See [docs/PLAN.md](docs/PLAN.md) for the full plan.
